# Сайт-визитка

Небольшой адаптивный сайт на русском языке без внешних зависимостей.

## Запуск

Откройте `index.html` в браузере или запустите локальный сервер:

```sh
cd /workspace/test
python3 -m http.server 8000 --bind 127.0.0.1
```

## Настройка

Измените имя, описание и услуги в `index.html`. Замените пример `hello@example.com` в тексте и в `mailto:` на настоящий адрес перед публикацией. Цвета и оформление находятся в `style.css`.

Сайт можно разместить на любом статическом хостинге. Сборка не требуется.
